- Language: TypeScript
- Styling: Tailwind CSS + shadcn/ui

- Auth: Firebase Auth
- AI: Google Gemini
- Payment: Payamgo
- Icons: Lucide

#### Product Decisions
- Target: Cameroonian students (GCE, BAC, class exams)
- Model: Freemium (1 free project, paid for 2+)
- Features: AI Chat, Past Questions, Notes Summarizer, Q&A Practice, Study Planner
