# LOOKA - PROJECT BRIEF

## Project Overview

**Name:** Looka

**Tagline:** AI-Assisted Exam Prep Platform

**Description:** An AI-powered platform helping students prepare for exams with past questions, AI assistance, study plans, and structured resources - specifically designed for the Cameroonian education system.

**Product Type:** Web Application (marketing website + authenticated webapp)

**Launch Date:** September 6, 2026

---

## Problem

Students in Cameroon face a critical challenge: despite having access to resources like YouTube, tutors, and AI tools (ChatGPT, Gemini), they lack:

1. **Will to study** - Students depend on cheating and malpractice instead of genuine learning
2. **Structured resources** - No centralized platform for Cameroonian exams (GCE, BAC, class exams)
3. **Guidance** - Existing tools provide information but not a clear study path
4. **Accountability** - No system to track progress and maintain study habits

**Consequence:** Loss of basic knowledge and academic integrity.

## MVP Scope

### Must-Have Features (v1)

1. **AI Chatbot**
   - Third-party AI integration
   - Exam-focused assistance
   - Context-aware responses

2. **Past Questions Section**
   - Browse by exam type, subject, year
   - Search functionality
   - Clean presentation

3. **Study Guide Planner**
   - Topic breakdown by subject
   - Daily schedule generator
   - Progress tracking

4. **Notes Summarizer**
   - Upload documents (PDF, images)
   - AI-powered summarization
   - Clean, readable output

5. **Question Answer Session**
   - Flashcards mode
   - MCQ (Multiple Choice Questions)
   - Active recall practice

### Deferred to v2

- Advanced analytics
- Gamification features
- Social/community features
- Mobile app
- Teacher content upload
- Institution dashboards

### Success Metrics
- User reviews and feedback
- Premium subscriber conversion
- User retention rate
