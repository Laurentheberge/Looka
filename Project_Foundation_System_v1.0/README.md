# PROJECT FOUNDATION SYSTEM

Version 1.0
Created by No1Vibecoder

A 7-step workflow for taking an idea from project discovery through product requirements,
technical foundation, AI rules, implementation, testing, and deployment.

## How to use

Use the steps in order. Paste each step into your AI coding workflow when you reach that
stage. Keep the generated project documents in the `docs/` directory.

Do not skip directly to building. Each step exists to reduce guessing and keep the AI,
project requirements, architecture, design, code, testing, and deployment aligned.

## Steps

1. Project Discovery
2. Product Requirements
3. Technical Foundation
4. AI Development Rules
5. Build
6. Test and Harden
7. Deploy and Launch

## Style rules

Project copy should be natural and human-readable. Avoid unnecessary emojis, decorative
symbols, em dashes, en dashes, excessive ellipses, filler phrases, and overly AI-sounding
language.

## Important

The AI should not claim something is working, tested, secure, deployed, or verified unless
it has actually checked it.
